## Verdict

| Axis | Stamp | Why |
|---|---|---|
| **Signal — is the effect real?** | ![Weak](https://img.shields.io/badge/Weak-dab617?style=flat-square) | The *claimed* effect (a positive buy-the-dip rebound) is decisively **not** there — the rebound is negative (−9.3%, *t* = −2.36, right-tail p = 0.997), the reverse of the folklore. There is a suggestive post-scare *downdrift*, but it is fragile: n = 6, four of which are one autocorrelated 2015 crisis, with two December windows overlapping. Not indistinguishable from noise, but nowhere near robust. |
| **Tradability — survives costs/scale?** | ![Mirage](https://img.shields.io/badge/Mirage-c0392b?style=flat-square) | Nothing to bank. "Buy the dip" loses ~9–10% per event net; the inverse short is a 6-event, one-episode, hard-to-borrow curiosity. No capacity, no independence, no edge you could run. |

> **In one sentence:** the scare is a real dip, but you should *not* buy it — across six real
> Chipotle food-safety scares CMG kept falling for a month (−9.3% vs SPY, *t* = −2.36) rather
> than rebounding, so the contrarian reflex is a falling-knife, and even that "keep-shorting"
> inverse is a fragile, un-bankable artifact of the 2015 crisis rather than a strategy.
