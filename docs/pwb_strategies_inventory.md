# Papers-With-Backtest — strategy backlog inventory

> Triaged from the **63 open strategies** in the public [paperswithbacktest/awesome-systematic-trading](https://github.com/paperswithbacktest/awesome-systematic-trading) table (the *previous list*; the live ~140 are now behind paperswithbacktest.com). Each row carries a QuantConnect reference implementation (linked) and a source paper, plus the desk's own feasibility tier and a flag for overlap with an already-shipped study. Companion to `papers/151_strategies_inventory.md`.

**Reading the Sharpe column:** these are the *vendor's* headline Sharpes — in-sample, gross of realistic costs, and exactly the figure the desk's MIRAGE axis exists to stress-test. Treat a high Sharpe as a *claim to debunk*, not a promise. Ordered by it only to mirror the source.

**Tiers** — **A**: price-only equity/ETF, frappable now (yfinance; free HF single-name stocks for deep history via `quantlab.hf_data`). **B**: needs fundamentals / FX / macro — partially covered by SEC EDGAR EPS + `tools/fetch_altdata.py`. **C**: blocked here (options chains, intraday/1-min, or an exotic feed we have no free source for).

**At a glance:** 63 strategies — Tier A **27**, Tier B **23**, Tier C **13**. 22 overlap an existing study; **41 are net-new** hypotheses for studies 40+.
